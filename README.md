## What is Dash Client?

Dash Client is a custom launcher and mod bundle for Minecraft: Java Edition. You install it, sign in with your own Microsoft account, press **Launch**, and it takes care of the rest: game files, Java, the Fabric loader and a set of performance mods.

No manual mod installs, no Java setup, no folders to dig through.

## Features

**Launcher**
- Clean dark UI with smooth animations and blur effects
- Sign in with your own Microsoft account
- Automatic download of Minecraft, libraries, assets and Java
- Automatic Fabric + Fabric API setup
- RAM slider and game folder settings
- Pick the Minecraft version you want to play

**Performance Mods** (one toggle, installed together)
- [Sodium](https://modrinth.com/mod/sodium): faster rendering
- [Lithium](https://modrinth.com/mod/lithium): game logic optimisation
- [FerriteCore](https://modrinth.com/mod/ferrite-core): lower memory usage
- [ImmediatelyFast](https://modrinth.com/mod/immediatelyfast): faster HUD and text rendering
- [Entity Culling](https://modrinth.com/mod/entityculling): skips entities you can't see

**Dash Client mod** *(in development)*
- In-game menu with a module grid
- HUD modules (FPS, keystrokes, coordinates, armor, potion effects)
- Zoom, free look and custom hitboxes
- Drag-and-drop HUD layout editor

## How it works

1. You sign in with Microsoft in your normal web browser.
2. The launcher downloads Minecraft directly from Mojang's servers.
3. It installs Fabric, Fabric API and the mods you have enabled.
4. It starts the game with your own session.

## Privacy and security

- Sign-in uses the standard Microsoft login page in **your browser**. The launcher never sees your password.
- Your login token is stored **encrypted on your own PC** and is never sent to any server run by Dash Client.
- Game files come straight from Mojang. Mods come from [Modrinth](https://modrinth.com) and the Fabric project.
- There is **no offline or cracked-account mode**. You need to own the game.

## FAQ

**Is it free?**
Yes. Dash Client is free and non-commercial.

**Do I need to own Minecraft?**
Yes, you need Minecraft: Java Edition on your Microsoft account.

**Will it get me banned?**
Dash Client is built around client-side performance and interface features. Always check a server's rules before joining. Some servers restrict certain modules (for example zoom or free look) and you are responsible for following them.

**Mac or Linux?**
Not at the moment. Windows only.

**Windows says "Windows protected your PC".**
The early builds are not code-signed yet. Click **More info**, then **Run anyway**, if you downloaded the installer from this page.
